# Starter vocabulary

Verified high-frequency Hong Kong Cantonese, weighted toward words that come up
while working. Use these freely. Anything outside this list is fine too, as long
as you are confident of the tone numbers and that a Hong Kong speaker would
actually say it — see [Mandarin traps](#mandarin-traps) before reaching further.

Columns: Jyutping | characters | gloss.

## Social

| Jyutping | 漢字 | English |
|---|---|---|
| nei5 hou2 | 你好 | hello |
| zou2 san4 | 早晨 | good morning |
| m4 goi1 | 唔該 | thanks / please / excuse me |
| do1 ze6 | 多謝 | thank you (for a gift or kindness) |
| m4 sai2 haak3 hei3 | 唔使客氣 | you're welcome |
| deoi3 m4 zyu6 | 對唔住 | sorry |
| m4 hou2 ji3 si1 | 唔好意思 | excuse me / my apologies |
| baai1 baai3 | 拜拜 | bye |
| gaa1 jau4 | 加油 | keep at it |

`m4 goi1` vs `do1 ze6`: `m4 goi1` for service and small favours (and for "please"),
`do1 ze6` for gifts and real kindness. Mixing them up is the classic learner tell.

Note: Hong Kong speakers say a lot of tech vocabulary in English inside Cantonese
sentences — "file", "app", "server", "email". Don't invent Cantonese for terms
people don't actually use in Cantonese; it teaches something nobody will say back.

## Sentence-final particles

Cantonese carries a lot of tone-of-voice in particles at the end of a sentence.
They are hard to gloss cleanly, so use them sparingly and only where the mood is
obvious from context.

| Jyutping | 漢字 | Effect |
|---|---|---|
| laa1 | 啦 | softens a suggestion — "let's just..." |
| laa3 | 喇 | something has changed — "it's done now" |
| aa3 | 呀 | general softener, takes the edge off |
| me1 | 咩 | surprised question — "really?" |
| lo1 | 囉 | "obviously" / resigned |
| wo3 | 喎 | "hey, notice this" |

## Mandarin traps

Written Standard Chinese read out in Jyutping is not Cantonese. If a sentence
feels like it came from a textbook, check it against this table. The left column
is what a Hong Kong speaker says.

| Say this | Not this | Meaning |
|---|---|---|
| hai6 係 | si6 是 | is |
| m4 唔 | bat1 不 | not |
| mou5 冇 | mut6 jau5 沒有 | don't have |
| ge3 嘅 | dik1 的 | possessive ('s) |
| mat1 je5 乜嘢 | sam6 mo1 什麼 | what |
| bin1 dou6 邊度 | naa5 leoi5 哪裡 | where |
| dim2 gaai2 點解 | wai6 sam6 mo1 為什麼 | why |
| ni1 go3 呢個 | ze5 go3 這個 | this one |
| go2 go3 嗰個 | naa5 go3 那個 | that one |
| tai2 睇 | hon3 看 | look / watch |
| sik6 食 | hek3 吃 | eat |
| jam2 飲 | hot3 喝 | drink |
| lei4 嚟 | loi4 來 | come |
| wan2 搵 | zaau2 找 | find |
| sai3 細 | siu2 小 | small |

## Vocab log template

If `~/.claude/cantonese-vocab.md` does not exist, create it like this:

```markdown
# Cantonese vocab log

Ambient learning log for the `cantonese` skill. Lives outside any repo on
purpose — it follows me between projects and should never be committed.

Format: `jyutping | 漢字 | english | seen N | since YYYY-MM-DD`

## Learning

hou2 | 好 | good / very | seen 1 | since 2026-09-17

## Known

_Words past ~15 sightings. These can appear without the bracketed translation._
```
